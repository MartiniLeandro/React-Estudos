# Frontend - OnSign Challenge

## About

Frontend application responsible for displaying processed user suggestions generated by the backend service.

## Features

- User suggestion table
- Suggested friends visualization
- Suggested interests visualization
- Responsive layout
- Backend API integration

## Technologies

- React
- TypeScript
- TailwindCSS
- Axios
- Vite

## Installation

Install dependencies:

```bash
npm install
```

## Running the Application

The frontend should run on the default Vite port (`5173`) to match the backend CORS configuration.

Start the development server:

```bash
npm run dev
```

## Default URL

http://localhost:5173

## Application Behavior

When accessing the root route (`/`), the application automatically fetches and displays all processed user suggestions from the backend API.

No additional configuration or user interaction is required.
